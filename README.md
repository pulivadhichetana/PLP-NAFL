# National Academy for Learning — Lesson Plan & Worksheet Studio

A single-file, browser-based AI tool that helps teachers create **CBSE lesson plans, worksheets, and chapter objectives** for **all subjects, Grades 1–12**, and download them as **editable Word (.docx) and PDF**.

No build step, no server, no install — it is one HTML file.

---

## ✨ What it does

- **Build lesson plans** in the school's *In-session* format from a topic + chosen activities.
- **Objective-driven content** — activities are filled with *real* questions, prompts and worked examples for your topic (not generic outlines), generated by AI.
- **Bloom's taxonomy objectives** — one click generates measurable objectives using Bloom action verbs across cognitive levels.
- **Teacher Mini-Lecture** — a subject-knowledge talking-points script + questioning prompts for each topic.
- **Worksheet generator** — True/False, MCQ, Fill-in-the-blanks, Short answer (with **marks**), coding *find-the-error* / *write-the-output*, and an **image/diagram box** (map work, label-the-diagram, etc.). Questions can be **AI-drafted** and aligned to your objectives.
- **Convert a file** — upload a PPT / PDF / Word lesson and reformat it into the school template.
- **Plan of Work** — upload a syllabus PDF to list chapters and draft objectives per chapter.
- **Source-grounded** — AI content is grounded in **NCERT/CBSE** textbooks, and for Computer Science also in resources like **opencs.com** and *Happy Coder*-style textbook content.

## 🔑 Enabling AI — free option included

AI features (objectives, activity content, worksheet questions, mini-lecture) need an AI provider. You choose in **⚙ AI Settings**:

- **Google Gemini — FREE.** Get a free key at <https://aistudio.google.com/apikey> (needs a Google account, takes ~1 minute). The free tier is enough for normal classroom use. **Recommended.**
- **OpenAI / ChatGPT — paid.** Get a key at <https://platform.openai.com> → API keys. Note: an OpenAI/ChatGPT *subscription* is separate and does **not** work here — you need an API key, which is billed per use.

Steps: open the app → click **⚙ Turn on AI** (or the banner) → choose **Gemini**, paste your key, **Save**. The key is stored only on your own device (localStorage) and is never uploaded or committed to the site.

> **Why can't it use my ChatGPT login automatically?** Browser security (CORS) and OpenAI's design make it impossible for a website to use someone's ChatGPT account. A per-user API key (Gemini's is free) is the correct, secure way.

Without a key, the tool still builds plans/worksheets from editable templates and **all downloads work** — only the AI-written content is disabled, and the app tells you clearly when that happens.

## ⬇ Downloads

Click **Word (.docx)** or **PDF** in the preview. A panel appears with a **Download** button (works even where automatic downloads are blocked) and an **Open in new tab** button — handy on phones, where you then use the browser's **Save** or **Print → Save as PDF**. A small **diagnostics** link shows what your device supports if anything misbehaves.

## 🚀 Hosting on GitHub Pages (recommended)

The file must be **served** (not viewed through GitHub's file preview, which does not run JavaScript).

1. Put `index.html` in the repository root.
2. Repo **Settings → Pages → Source: Deploy from a branch → main → /(root)**.
3. Your live tool will be at `https://<your-username>.github.io/<repo-name>/`.

Opening the raw `index.html` locally (double-click) also works for downloads; AI needs internet.

## 🧩 Tech notes

- Pure HTML/CSS/JS, **zero external libraries** at runtime. Word (.docx) and PDF are generated in-browser with a custom OOXML/PDF writer and a from-scratch ZIP/DEFLATE implementation.
- Reads .pptx/.docx/.pdf in-browser (unzip + inflate written from scratch).
- Tested in a real Chromium browser: objective generation, content grounding, all four export paths (lesson docx/pdf, worksheet docx/pdf) verified and the .docx files pass OOXML validation.
