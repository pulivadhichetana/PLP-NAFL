# National Academy for Learning — PLP-NAFL-SPARK Portal

A single-file, browser-based AI tool that helps teachers create **CBSE lesson plans** and **Plans of Work** for **all subjects, Grades 1–12**, and download them as **editable Word (.docx) and PDF** — in the school's exact *In-session* lesson plan format.

No build step, no server, no install — it is one HTML file.

---

## ✨ What it does

- **Build lesson plans** in the school's *In-session* format (Time | Teacher Activity | Learner Activity | Formative Assessments | Resources) from a topic + chosen activities, drawn from the school's Goody Bag activity library.
- **Objective-driven content** — activities can be filled with *real* questions, prompts and worked examples for your topic (not generic outlines), generated by AI.
- **Bloom's taxonomy objectives** — one click generates measurable objectives using Bloom action verbs across cognitive levels.
- **Teacher Mini-Lecture** — a subject-knowledge talking-points script + questioning prompts for each topic.
- **Convert a file** — upload a PPT, PDF, or **Word** lesson and reformat it into the school template.
  - For **Word (.docx)** files, the reader is *table-aware*: if the file has a Time/Teacher/Learner/Resources table (the same shape as the school's own lesson plans), the columns are mapped directly — accurate, not guessed.
  - If no recognisable activity or table is found, you're offered the same activity-picker used in Build, so the plan is never built from a blind guess.
- **Plan of Work** — upload a syllabus PDF to list chapters/topics, draft Bloom-aligned objectives for each, and generate a teacher-chosen number of full lesson plans per topic — each using different activities from the Goody Bag library. Pick from a Resources dropdown (Computer Lab, Whiteboard, Library, etc.) to control what's used. Export as a **Topics → Objectives** table (matching the school's POW template) or a **Month → Objectives** year planner — both in portrait, Word and PDF identical.
- **Source-grounded** — AI content is grounded in **NCERT/CBSE** textbooks, and for Computer Science also in resources like **opencs.com** and *Happy Coder*-style textbook content.

## 🔑 Enabling AI — free option included

AI features (objectives, activity content, mini-lecture, Plan of Work objectives) need an AI provider. Choose one in **⚙ AI Settings**:

- **Google Gemini — FREE.** Get a free key at <https://aistudio.google.com/apikey> (needs a Google account, takes ~1 minute). The free tier is enough for normal classroom use. **Recommended.**
- **OpenAI / ChatGPT — paid.** Get a key at <https://platform.openai.com> → API keys. Note: an OpenAI/ChatGPT *subscription* is separate and does **not** work here — you need an API key, which is billed per use.

Steps: open the Portal → click **⚙ Turn on AI** (or the banner) → choose **Gemini**, paste your key, **Save**. The key is stored only on your own device (browser localStorage) and is never uploaded or committed to the site.

> **Why can't it use my ChatGPT login automatically?** Browser security (CORS) and OpenAI's design make it impossible for a website to use someone's ChatGPT account directly. A per-user API key (Gemini's is free) is the correct, secure way.

Without a key, the Portal still builds plans from editable templates and **all downloads work** — only the AI-written content is disabled, and the app tells you clearly when that happens (it never fails silently).

## ⬇ Downloads

Click **Word (.docx)** or **PDF** in the preview. A panel appears with a **Download** button (works even where automatic downloads are blocked), an **Open in new tab** button — handy on phones or for printing, where you then use the browser's **Print → Save as PDF** — and a backup link for restrictive browsers. A small **diagnostics** link shows what your device supports if anything misbehaves.

## 🚀 Hosting on GitHub Pages (recommended)

The file must be **served** (not viewed through GitHub's file preview, which does not run JavaScript).

1. Put `index.html` in the repository root.
2. Repo **Settings → Pages → Source: Deploy from a branch → main → /(root)**.
3. Your live Portal will be at `https://<your-username>.github.io/<repo-name>/`.

Opening the raw `index.html` locally (double-click) also works for downloads; AI needs internet.

## 🧩 Tech notes

- Pure HTML/CSS/JS, **zero external libraries** at runtime. Word (.docx) and PDF are generated in-browser with a custom OOXML/PDF writer and a from-scratch ZIP/DEFLATE implementation.
- Reads .pptx/.docx/.pdf in-browser (unzip + inflate written from scratch). The .docx reader parses actual table rows/columns, not just flat paragraph text, so uploaded lesson plans with a Time/Teacher/Learner/Resources table convert accurately.
- Tested in a real Chromium browser end-to-end: lesson build, AI content injection, Word-table conversion, Plan of Work generation (including multi-lesson-plan generation), and all export paths — `.docx` files pass OOXML validation.
